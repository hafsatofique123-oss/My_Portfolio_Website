# Personal Developer Portfolio Template

A responsive, dark-gradient developer portfolio starter built with HTML5, Tailwind CSS utilities, custom CSS, and vanilla JavaScript.

## Files
- `index.html` — semantic page structure and all portfolio sections
- `style.css` — custom theme, responsive layouts, gradients, and animations
- `script.js` — mobile navigation, dark/light toggle, project details dialog, reveal effects
- `assets/` — place your profile photo, resume PDF, and other local assets here

## Run locally
1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. An internet connection is needed for the Tailwind browser CDN and Google Fonts.

## Personalize before publishing
Search the files for square-bracket placeholders such as `[Your Full Name]` and replace them with accurate information.
Also update:
- `YOUR.NAME` in the navigation and footer
- page title and meta description
- email, LinkedIn, and GitHub URLs
- project descriptions, technologies, GitHub links, and modal data in `script.js`
- education, certificates, resume details, and profile photo placeholder

Only list skills, qualifications, and experience that you genuinely have. Replace every example `href="#"` with a real destination or remove that link if you do not have one yet.

## Tailwind note
This starter uses Tailwind's browser CDN for easy learning and quick setup. For a production deployment, follow the current official Tailwind CSS installation guide and generate a compiled CSS file. Custom CSS in `style.css` supplies the gradient theme and interactions.

## Deploy
You can deploy this static site using GitHub Pages, Netlify, or Vercel. No backend or database is required for this frontend-only version.

## Contact section
The contact CTA uses a `mailto:` link. It does not submit or store form data. A working contact form would require a form service or backend.
